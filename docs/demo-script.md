# Jury demo (2–3 minutes)

Use a fresh browser profile so the economy starts at 1,000 credits. The values below are the game's illustrative part prices, not real launch costs.

## Run of show

**0:00–0:20 — Introduce the game**  
“Space Mission Design Game teaches how rocket choices affect mass, thrust-to-weight ratio, fuel capacity, and mission trade-offs. Our flight and economy models are intentionally simplified, and we distinguish NASA facts from game assumptions.”

**0:20–0:55 — Design a success case**  
Open **Yeni Görev**. Select **Hafif Keşif**, **Spark**, **Genişletilmiş tank**, and **Güneş paneli**. Point out the 2.5D rocket, approximately 1.2 TWR, live mass/cost, and the budget balance. Continue to the mission screen; select the Moon and powered descent; start and launch. Let the Phaser ascent reach apogee and show the result, +100 credits/+150 SP, and Moon base energy production. The example fits within the starting budget.

**0:55–1:35 — Show a science-based failure**  
Return to assembly and use the same parts without cargo (or another affordable configuration with enough Moon/Mars Delta‑V). Choose Mars, turn off the heat shield and powered descent, then launch. The result explains that the simplified Mars landing rule requires both systems. The flight cost is not refunded.

**1:35–2:05 — Show persistence and colony progress**  
Open the base panel to show the delivered solar panel, energy, science, current balance, and mission history. Refresh once and confirm the record persists in that browser profile.

**2:05–2:30 — Close with limits**  
“The flight scene is 1D vertical ascent, not an Earth-to-Mars trajectory. NASA sources inform rounded gravity and atmospheric facts; Delta‑V targets, part specifications, prices, rewards, and production are game assumptions.” Point to `docs/nasa-data-usage.md` and the submission checklist.

## If time is short

Skip the second flight and show the prewritten mission rules in the report. Keep the success flight; it demonstrates the complete award-and-base loop. Never describe the result as a real mission feasibility result.
